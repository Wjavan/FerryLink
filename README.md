**👉 一个免费开源的网盘下载助手 👈**

【FerryLink】是一款免费开源 **获取网盘文件真实下载地址** 的油猴脚本，支持 Windows、Mac、Linux，内置 **多种热门下载器与下载协议**：既能一键把直链推送给 IDM、Aria2、Motrix、BitComet，也能复制 cURL、aria2c 命令到终端自己跑。

> ⚠️ **建议配合网盘超级会员使用** — 本助手仅解析下载链接，不突破网盘限速

---

## 💡 功能特性

| 特性 | 说明 |
|------|------|
| 🎯 **六大网盘支持** | 百度网盘、阿里云盘、天翼云盘、迅雷云盘、夸克网盘、中国移动云盘 |
| 🧩 **统一下载面板** | 先选下载器、再选协议，任意组合；文件再多也不会把弹窗挤爆 |
| ⚡ **推送型协议** | IDM 本地 HTTP API、Aria2 / Motrix JSON-RPC、BitComet 远程下载 |
| 🔗 **多链下载** | 开 4 路并发分段取回再合并，单连接被限速时能叠加带宽 |
| 🔀 **转码链路** | 迅雷云盘可用：视频文件另有一条服务器链路，与原始直链并存，需要时可换用 |
| 🧾 **复制型协议** | cURL、aria2c 命令（自动带上该网盘需要的 UA / Cookie），BC（复制 `bc://` 地址调起 BitComet） |
| 📦 **批量获取** | 一次勾选多个文件，集中取链、批量推送 |
| 🎨 **外观自定义** | 7 种主题颜色 + 深色模式（浅色 / 深色） |
| 🔒 **配置内嵌本地** | 配置全部存在脚本本地，不依赖第三方服务器；子页支持「测试连接」「恢复默认」 |

---

## 🔧 下载器适配

| 下载器 | 可选协议 | 说明 |
|--------|----------|------|
| **浏览器** | HTTP 直链 / 多链下载 / 转码 | 直链交给浏览器原生下载，百度超过 50MB 的文件会被 CDN 拒绝。多链下载与转码仅迅雷云盘可用：前者由脚本并发分段取回后存盘，后者改用服务器另给的视频链路 |
| **IDM** | 本地 HTTP API | 推送到 IDM 本机接口 `127.0.0.1:1001`，需 IDM 已启动、且浏览器扩展已注册 client |
| **Aria2** | Aria2c / JSON-RPC | JSON-RPC 远程添加任务；Aria2c 复制命令行 |
| **Motrix** | Aria2c / JSON-RPC | 同上，Motrix 默认 RPC 端口 `16800` |
| **BitComet** | BC / BC-RPC | BC-RPC 需要 BitComet 开启「远程下载」；没开启时会自动改用 BC 调起本机客户端 |
| **XDown** | HTTP 直链 | 复制直链，粘到 XDown 里新建任务即可 |
| **终端** | cURL / Aria2c | 复制命令到 CMD / PowerShell / Linux / MacOS 终端执行 |

## 📖 使用说明

1. **登录网盘** — 打开对应网盘的网页版并登录账号
2. **勾选文件** — 在网盘页面勾选要下载的文件（可多选）
3. **点击按钮** — 点击页面上出现的 **「下载助手」** 按钮，弹出下载面板
4. **选下载器 → 选协议** — 面板里先点下载器（IDM / Aria2 / BitComet …），再点它支持的协议
5. **点主按钮** — 按钮文字跟着协议走：**开始下载** / **推送下载任务** / **复制命令**

> 💡 面板右下角的 **「助手设置」**（同油猴菜单里的「设置」）用来配置 Aria、BitComet、IDM、终端类型、主题颜色和深色模式。

---

## ⚙️ 配置说明

入口：**油猴菜单 → 设置**，或下载面板右下角的 **「助手设置」**。两个配置子页底部都有「恢复默认」和「测试连接」。

### Aria 配置（Aria2 / Motrix）

| 配置项 | 默认值 | 说明 |
|--------|--------|------|
| RPC 主机 | `http://localhost` | 要带上 `http://` |
| RPC 端口 | `16800` | Motrix 默认 16800，Aria2 默认 6800 |
| RPC 路径 | `/jsonrpc` | 默认路径，一般不用改 |
| RPC 密钥 | （空） | 没设密钥就留空 |
| 保存路径 | `C:` | 留空则使用 aria2 的默认下载目录 |

### BitComet 配置

| 配置项 | 默认值 | 说明 |
|--------|--------|------|
| 服务器地址 | `http://localhost` | BitComet 所在机器的地址 |
| 端口 | `8080` | 网页远程访问的端口 |
| 接口路径 | `/panel/task_add_httpftp_result` | 默认路径，一般不用改 |
| 账号 / 密码 | （空） | 没开访问控制就留空 |
| 保存路径 | （空） | 留空则使用 BitComet 默认目录 |

> BC-RPC 需要先在 BitComet 里开启 **选项 → 网络连接 → 远程下载 → 通过网页远程访问**，再把端口填到上面。

### 其他

| 配置项 | 默认值 | 说明 |
|--------|--------|------|
| IDM 客户端 ID | `1` | IDM 里配多个客户端时用来指定编号 |
| 终端类型 | Windows CMD | 另有 Windows PowerShell / Linux 终端 / Linux Shell / MacOS 终端 |
| 主题颜色 | `#09AAFF` | 7 种预设颜色 |
| 深色模式 | 浅色 | 浅色 / 深色 |

## 📝 注意事项

- ⏰ 各网盘下载直链均**有时效性**，过期后请重新获取
- 🐢 部分网盘对直链下载**有限速**，属官方限制，脚本无法突破
- ☁️ 百度网盘**超过 50MB 的文件**用浏览器直接下载会失败（CDN 拒绝浏览器 UA），改用 IDM / Aria2 / cURL / BitComet 都可以
- 🔑 迅雷的下载链接由**签名 + Cookie + UA** 三重校验，Cookie 过期时刷新网盘页面重新取链即可
- 🔀 迅雷的**转码**是服务器另给的一条视频链路，直链不可用或过慢时可换这条
- 🔒 脚本只在你本机取链和推送，**不存储、不上传任何用户数据**
- 🔌 推送没反应时先确认下载器已启动（IDM / Aria2 / Motrix / BitComet），配置子页的「测试连接」可以直接排查
