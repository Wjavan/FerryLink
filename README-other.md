# 🚀 FerryLink

一个免费开源的 **网盘直链下载油猴脚本**，支持 Windows / Mac / Linux，兼容 IDM、Aria2、Motrix、BitComet、XDown、终端等主流下载器。

---

## 📖 简介

【FerryLink】是一款 Tampermonkey 用户脚本，注入百度网盘、阿里云盘、天翼云盘、迅雷云盘、夸克网盘、移动云盘、城通网盘、光鸭云盘页面，自动识别并解析文件的真实下载地址。面板里先选下载器、再选协议，即可把直链推送或复制到你选择的下载器。

> ⚠️ 本脚本仅解析下载链接，不突破网盘限速，建议配合超级会员使用。

---

## ✨ 功能特性

- 🎯 **多网盘支持** — 百度 · 阿里 · 天翼 · 迅雷 · 夸克 · 移动 · 城通 · 光鸭
- 🧩 **统一下载面板** — 先选下载器、再选协议，任意组合
- ⚡ **多种协议** — 直链 · 多链下载 · 转码 · 本地接口 · 远程接口 · cURL / aria2c 命令 · BC
- 🔗 **多链下载** — 多路并发分段取回后合并，单连接被限速时能叠加带宽（迅雷云盘）
- ⭐ **设为默认** — 把常用的下载器与协议组合记下来，下次打开面板自动选中
- 📦 **批量下载** — 一次勾选多个文件，集中取链、批量推送
- 🎨 **自定义主题** — 7 种预设颜色，支持深色模式
- 🔒 **配置内嵌本地** — 所有设置写入油猴存储，不依赖第三方服务器

## 📥 安装方法

1. 安装 [Tampermonkey（篡改猴）](https://www.tampermonkey.net/) 扩展（支持 Chrome / Edge / Firefox）
2. 进入扩展管理页，开启左下角 **「开发人员模式」**
3. 打开篡改猴详情，启用 **「允许用户脚本」** 和 **「允许访问文件 URL」**
4. 回到本页面，点击右上角 **「安装此脚本」** 按钮
5. Tampermonkey 弹出安装确认后点击 **安装** 即可

---

## 💡 使用方法

1. 登录对应网盘网页版
2. 勾选要下载的文件
3. 点击页面出现的 **「下载助手」** 按钮
4. 先点下载器，再点它支持的协议
5. 点主按钮 — 文字随协议变化：**开始下载** / **推送下载任务** / **复制命令**

> 💡 百度分享页、城通分享页与目录页同样支持。面板右下角的 **「助手设置」** 可配置各下载器参数与外观。

---

## ⚙️ 配置说明

油猴菜单 → **「设置」**，或下载面板右下角的 **「助手设置」**。可配置 Aria2 / Motrix 与 BitComet 的连接参数、IDM 客户端 ID、终端类型、主题颜色与深色模式。

---

## 📝 注意事项

- ⏰ 下载直链具有**时效性**，过期后请重新获取
- 🐢 部分网盘对直链下载**有限速**，属官方限制，本脚本无法突破
- ☁️ 百度网盘**超过 50MB 的文件**无法由浏览器直接下载，请改用其他下载器
- 🔒 脚本**仅解析下载链接**，不存储、不转发任何用户数据
- 📄 请勿用于非法用途
